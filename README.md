# STM32 + TMC2209 步进电机驱动开发板
> 一款集成完整电源保护、静音驱动、按键交互与显示扩展的开源步进电机控制方案

---

## 🎯 项目简介
本项目基于 STM32F103C8T6 主控与 TMC2209 静音驱动芯片，设计了一款功能完整的工业级步进电机驱动板。原理图采用**模块化分区设计**，电源、驱动、控制、接口电路边界清晰，保护机制完备；配套开箱即用的 Keil 固件库，支持恒速运行、梯形加减速等多种运动模式，适用于自动化装置、小型机器人、3D 打印附件等场景快速原型开发。

## 📐 原理图核心电路深度解析
原理图采用功能分区布局，整体划分为六大独立电路单元，设计兼顾可靠性、扩展性与调试便利性，可直接作为工程参考或二次开发基础。

### 🔌 1. 电源输入与保护电路
位于原理图左侧入口，是整机安全的第一道防线。
- **输入接口**：DC-005 直流电源座，支持 28V 直流输入
- **浪涌防护**：SMBJ28CA 瞬态抑制二极管（D2），可抑制输入尖峰电压，防范反接与浪涌冲击
- **前端滤波**：多级容感滤波网络，滤除电源线上的传导干扰
- **设计亮点**：采用「先保护、后滤波」的拓扑结构，最大限度保障后级电路安全

### ⚡ 2. 28V 转 5V 稳压电路
DC-DC 降压单元，为全板提供稳定的系统供电。
- **主控芯片**：LM2596S-5.0 高效开关稳压芯片（U4），经典 Buck 拓扑
- **储能滤波**：47μH 功率电感配合大容量输入输出电容，稳压精度高、带载能力强
- **输出特性**：稳定 5V 系统供电，同时为驱动逻辑、主控芯片与外设供电
- **设计优势**：开关电源转换效率高，大负载下发热小，支持长时间连续工作

### 🧠 3. STM32 主控单元
原理图核心控制区，负责运动指令计算与外设调度。
- **主控芯片**：STM32F103C8T6，Cortex-M3 内核，72MHz 主频
- **控制引脚映射**：
  - PA0 → STEP 步进脉冲输出
  - PA1 → DIR 方向控制信号
  - PA2 → EN 驱动器使能控制
- **外设引出**：I2C 总线（SCL/SDA）、按键 IO、状态指示全部引出
- **设计特点**：最小系统精简可靠，预留充足 IO 资源，支持后续功能扩展

### 🚦 4. TMC2209 电机驱动电路
原理图右侧功率区，电机驱动的核心部分。
- **驱动芯片**：TMC2209 超静音步进驱动芯片
- **控制模式**：标准 STEP/DIR 脉冲控制模式，兼容主流运动控制逻辑
- **细分配置**：硬件配置 16 细分，电机运行平滑、低振动低噪音
- **输出接口**：M1A / M1B / M2A / M2B 两相四线电机端子
- **保护特性**：芯片内置过流、过热、欠压保护，大幅提升系统可靠性

### 🎛️ 5. 按键与状态指示电路
人机交互单元，便于本地调试与状态观测。
- **按键输入**：4 路独立按键电路（KEY1~KEY4），可自定义启停、正反转、调速等功能
- **状态指示**：LED2 电源指示灯，上电即亮，直观反映系统供电状态
- **电路设计**：按键电平匹配设计，软件可直接读取，无需额外外围配置

### 📺 6. 扩展与调试接口
原理图上下侧接口区，兼顾功能扩展与开发调试。
- **OLED 显示接口**：标准 I2C 接口（3V3、SCL、SDA、GND），直插 0.96 寸 OLED 屏
- **调试排针**：全引脚引出排针，支持 SWD 程序下载、串口调试与功能扩展
- **接线端子**：插拔式接线端子，电机接线牢固可靠，适配工业场景

## 💻 固件功能说明
配套完整的 C 语言驱动库，基于 STM32 标准库开发，可直接在 Keil MDK 中编译使用。

### 核心驱动能力
1. **基础运动控制**
   - 正/反转方向精准切换
   - 定步数精确位置控制
   - RPM 转速模式连续运行

2. **高级运动算法**
   - 梯形加减速控制，长距离运行不丢步
   - 可配置启动转速、最高转速、加减速步数
   - 内置调速扫描测试函数，快速调试电机参数

3. **驱动管理**
   - 驱动器使能/失能软件控制
   - 方向信号建立延时保护
   - 脉冲时序严格符合芯片规格

### 关键配置参数（step_motor.h）
```c
#define PULSE_PER_ROUND   3200   // 每圈脉冲数（16细分，200步电机）
#define PULSE_HIGH_US     5      // 脉冲高电平最小宽度
#define DIR_CW            1      // 顺时针正转
#define DIR_CCW           0      // 逆时针反转
```

## 🚀 快速上手

### 硬件准备
1. 将 28V 直流电源接入 DC1 电源座
2. 步进电机接入 M1A / M1B / M2A / M2B 端子
3. SWD 下载器连接对应调试排针

### 编译运行
1. Keil MDK 打开工程，选择 STM32F103C8 目标芯片
2. 在 `main.c` 中取消对应示例的注释
3. 编译工程并下载到开发板

### 内置示例代码
```c
// 示例1：基础正反转测试
StepMotor_RunRPM(60, DIR_CW, 1);   // 正转1圈，60转/分
StepMotor_RunRPM(60, DIR_CCW, 1);  // 反转1圈，60转/分

// 示例2：转速扫描测试
for(uint16_t r = 20; r <= 150; r+=10) {
    StepMotor_RunRPM(r, DIR_CW, 0.5);
}

// 示例3：梯形加减速长距离运行
StepMotor_MoveWithAccel(10000, DIR_CW, 20, 120, 2000);
```
