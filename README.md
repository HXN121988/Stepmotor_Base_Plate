# STM32 步进电机驱动板

一款基于 STM32F103C8T6 + TMC2209 的高性能步进电机驱动开发板，集成电源管理、按键交互、OLED 扩展接口，配套完整的 Keil 驱动库与示例代码，适合机器人、3D 打印机、数控设备等场景快速原型开发。

---

## ✨ 硬件核心特性

### 主控与驱动
- **主控芯片**：STM32F103C8T6，Cortex-M3 内核，72MHz 主频，资源丰富易于开发
- **驱动方案**：TMC2209 超静音步进电机驱动芯片，支持 16 细分，运行平稳低噪音
- **驱动能力**：最大 2A 相电流，适配 42 型及以下两相四线步进电机

### 电源系统
- **输入电压**：DC 28V 直流供电（DC-005 接口）
- **板载稳压**：LM2596S-5.0 开关稳压芯片，高效 5V 输出
- **保护电路**：SMBJ28CA 瞬态抑制二极管，防反接、防浪涌冲击
- **电源指示**：板载 LED 电源指示灯，工作状态一目了然

### 外设与接口
- **按键交互**：4 路独立按键（SW1/SW2/SW5/SW6），可用于模式切换、调速控制
- **显示扩展**：预留 I2C 接口（SCL/SDA/3V3/GND），直插 OLED 显示屏
- **电机接口**：标准 4P 电机接线端子，接线牢固可靠
- **调试接口**：预留排针，支持 SWD 在线仿真与下载

### 电路设计
- **PCB 工艺**：双层板设计，布局紧凑，走线规范
- **滤波网络**：多级 LC 滤波，电源纹波小，驱动更稳定
- **阻容选型**：全贴片元件，工业级温漂特性，工作可靠

## 🛠️ 软件功能

配套完整的 C 语言驱动库，基于 STM32 标准库开发，可直接在 Keil MDK 中编译使用。

### 驱动库功能
1. **基础运动控制**
   - 正/反转方向控制
   - 定步数精确运行
   - 转速（RPM）模式控制

2. **高级运动控制**
   - 梯形加减速算法，长距离运行防丢步
   - 可配置启动转速、最高转速、加减速步数
   - 调速扫描测试，便于调试电机最佳参数

3. **驱动管理**
   - 驱动器使能/失能控制
   - 方向信号建立延时保护
   - 脉冲宽度严格符合时序要求

### 配置参数（step_motor.h）
```c
#define PULSE_PER_ROUND   3200   // 每圈脉冲数（16细分，200步电机）
#define PULSE_HIGH_US     5      // 脉冲高电平最小宽度
#define DIR_CW            1      // 正转
#define DIR_CCW           0      // 反转
```

## 🚀 快速上手

### 硬件连接
1. 将 28V 直流电源接入 DC1 电源座
2. 步进电机接入 M1A/M1B/M2A/M2B 端子
3. 通过 SWD 接口连接下载器

### 编译与下载
1. 使用 Keil MDK 打开工程
2. 选择目标芯片 STM32F103C8
3. 编译工程并下载到开发板

### 运行示例
`main.c` 中内置 3 组示例，取消对应注释即可运行：

```c
// 示例1：基础正反转
StepMotor_RunRPM(60, DIR_CW, 1);   // 正转1圈，60转/分
StepMotor_RunRPM(60, DIR_CCW, 1);  // 反转1圈，60转/分

// 示例2：调速扫描测试
for(uint16_t r = 20; r <= 150; r+=10) {
    StepMotor_RunRPM(r, DIR_CW, 0.5);
}

// 示例3：梯形加减速长距离运行
StepMotor_MoveWithAccel(10000, DIR_CW, 20, 120, 2000);
```
