## ✨ 项目特性
### 🛠️ 硬件特性
- **一体化电源设计**：板载28V转5V DC-DC电路，自带输入输出双路TVS浪涌保护，无需额外电源模块
- **工业级防护**：电源端防浪涌、过压钳位设计，适配不稳定供电场景
- **即插即用驱动**：标准排针接口直插TMC2209模块，无需额外布线，更换驱动方便
- **丰富扩展资源**：引出I2C OLED接口、4路用户按键，支持人机交互与二次开发
- **紧凑化设计**：布局优化，体积小巧，适合嵌入小型运动设备与DIY项目

### 🧾 软件特性
- 支持定步数恒速、定转速圈数、梯形加减速三种运动控制模式
- 基于SysTick的微秒级精确延时，脉冲时序稳定，丢步风险低
- 全宏定义引脚配置，硬件适配灵活，移植成本低
- 代码分层设计，注释完整，适合嵌入式学习与二次开发

## 🔧 硬件系统详解
### 整体架构
本底板采用「主控+驱动+电源」三段式分层架构，通过排母外接STM32F103C8T6最小系统板，板载完整电源保护与TMC2209驱动接口，接入电源与电机即可快速搭建运动控制系统。

```
          ┌─────────────────────────────────────────┐
          │           STM32F103C8T6 主控            │
          │  (排母外接，输出STEP/DIR/EN控制信号)    │
          └─────────────────┬───────────────────────┘
                            │ 控制信号
          ┌─────────────────▼───────────────────────┐
          │            TMC2209 驱动模块             │
          │      (插接式设计，电流可调)             │
          └─────────────────┬───────────────────────┘
                            │ 功率输出
          ┌─────────────────▼───────────────────────┐
          │            步进电机接线端子             │
          └─────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│  电源子系统：28V输入 → TVS保护 → DC-DC降压 → 5V输出  │
└─────────────────────────────────────────────────────┘
```

### 电源与保护电路
电源系统为本底板核心设计，提供完整的防护与稳压功能：
- **输入接口**：DC-005-A200 直流电源座，适配5.5*2.1mm标准电源插头
- **额定输入**：DC 28V
- **输入级防护**：SMBJ28CA 型TVS二极管，抑制浪涌尖峰，防止静电与电源冲击损坏后级电路
- **降压方案**：采用 TPS54302DDCR 同步降压芯片
  - 输出电压：5V
  - 最大输出电流：3A
  - 转换效率高，发热低，满足主控与外设供电需求
- **输出级防护**：SMBJ6.8A 型TVS二极管，钳位输出电压，保护后级主控与外设
- **状态指示**：板载LED电源指示灯，上电即亮，直观判断供电状态

### 电机驱动接口
- **驱动适配**：标准2.54mm排针接口，直插 TMC2209 步进电机驱动模块
- **电机端子**：ZX-HY2.0-4P 卧式接线端子，压线牢固，拆装方便
- **端子引脚定义**：

  | 端子标号 | 功能说明 |
  |:---:|:---|
  | M1A | 电机A相正端 |
  | M1B | 电机A相负端 |
  | M2A | 电机B相正端 |
  | M2B | 电机B相负端 |

- **适配电机**：支持42型及以下两相四线步进电机

### 外设扩展接口
1. **OLED显示接口**（I2C协议）
   - 引脚定义：GND / 3V3 / SCL / SDA
   - 兼容0.96寸、1.3寸等常见I2C接口OLED显示屏
2. **用户按键**
   - 4路独立轻触按键输入，可自定义功能
   - 板载上拉电阻，低电平触发
3. **主控排母**
   - 2.54mm间距排母，直接兼容STM32F103C8T6最小系统板
   - 引出电源、I2C、按键、控制信号等全部必要引脚

## 💻 软件驱动说明
软件开发环境为 **Keil MDK-ARM5**，基于STM32F10x标准外设库开发。

### 代码结构
```
software/
├── main.c              # 主程序，包含多组测试示例
├── step_motor.c        # 步进电机驱动逻辑实现
├── step_motor.h        # 驱动配置与函数声明
├── systick.c           # SysTick微秒/毫秒延时实现
└── systick.h           # 延时函数头文件
```

### 引脚映射
控制引脚定义在 `step_motor.h` 中，可根据硬件修改：
```c
#define STEP_PORT       GPIOA
#define STEP_PIN        GPIO_Pin_0     // 步进脉冲输出
#define DIR_PORT        GPIOA
#define DIR_PIN         GPIO_Pin_1     // 方向控制输出
#define EN_PORT         GPIOA
#define EN_PIN          GPIO_Pin_2     // 驱动器使能输出
```

### API接口
```c
// 初始化与使能控制
void StepMotor_Init(void);       // GPIO初始化
void StepMotor_Enable(void);     // 使能驱动器输出
void StepMotor_Disable(void);    // 关闭驱动器输出
void StepMotor_SetDir(uint8_t dir);  // 设置旋转方向

// 运动控制函数
void StepMotor_Steps(uint32_t steps, uint8_t dir, uint32_t pulse_interval_us);
void StepMotor_RunRPM(uint16_t rpm, uint8_t dir, uint32_t rounds);
void StepMotor_MoveWithAccel(uint32_t total_steps, uint8_t dir,
                             uint16_t start_rpm, uint16_t max_rpm, uint16_t acc_steps);
```

### 使用示例
```c
// 梯形加减速往返运动（长距离推荐，有效防止丢步）
// 参数：总步数10000，正转，启动20rpm，最高120rpm，加减速各2000步
StepMotor_MoveWithAccel(10000, DIR_CW, 20, 120, 2000);
Delay_ms(1000);
StepMotor_MoveWithAccel(10000, DIR_CCW, 20, 120, 2000);
Delay_ms(1000);
```

> 默认配置：`PULSE_PER_ROUND = 3200`，对应200步电机 + 16细分；修改该宏即可适配不同细分设置。

## ⚠️ 注意事项

> [!WARNING]
> 1. 电源输入严格为 **DC 28V**，禁止超压使用，否则会击穿TVS管与电源芯片。
> 2. TMC2209模块的驱动电流需提前通过电位器调节，不可超过电机额定电流，避免过热烧毁。
> 3. 驱动器失能状态下电机无锁止力矩，垂直安装设备时请做好负载防坠措施。

> [!NOTE]
> 1. SysTick时钟源配置为HCLK/8，请确保系统主频配置为72MHz，以保证延时精度。
> 2. EN引脚高电平为驱动器失能，低电平为使能，与TMC2209硬件逻辑一致。
> 3. PCB工程可直接导入嘉立创EDA进行修改、打样生产。
